    Cloud storage & backup

    When storage reaches half (512 MB), Ops backs up everything to Google Drive by itself: every record and every paper. It checks each copy, then clears the papers from here so the bar drops. Cleared papers still open from Drive. Anything you delete in Ops is removed from Drive too (papers go to the Drive trash for 30 days).

    Connect Google Drive so Ops can back everything up and clear space when it fills up. Set up once (about 5 minutes, best on a computer):

    1. Tap Copy the script.
    2. Open script.google.com with the Google account that should keep the backups. Delete what's in the editor, paste, and click 💾 Save.
    3. Deploy → New deployment → ⚙ → Web app. Execute as: Me. Who has access: Anyone. Click Deploy, then allow access (Advanced → Go to project → Allow).
    4. Copy the Web app URL, paste it below and tap Connect.
